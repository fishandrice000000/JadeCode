# s01-10 作业:真实 API 冒烟(风险闸门)

## 背景

s01 收官章,**没有代码作业,只有一场验收**。九章的成果第一次面对真实世界,要回答计划文档风险榜第一的问题:**anthropic-java SDK × DeepSeek 端点,Java 版到底能不能过?**(Python 跑通 ≠ Java 跑通)。过了,M0+s01 里程碑收官;过不去,启用 `HttpLlmClient` 后备(s01-4 把实现藏在 `LlmClient` 接口后,就是为这一刻准备的)。

## 前置检查

1. 项目根目录有 `.env` 且 `ANTHROPIC_API_KEY` 已填(没有就 `cp .env.example .env` 后填 key)
2. 默认值确认:baseUrl = `https://api.deepseek.com/anthropic`,model = `deepseek-v4-flash`(`.env` 不写就用默认)

## 验收六步(全部你自己跑)

1. `mvn -q package` → BUILD SUCCESS,产出 `target/jadecode.jar`
2. `java -jar target/jadecode.jar --version` → 打印版本,退出码 0
3. `./jade repl` → 出现欢迎语与 `s01 >>` 提示符
4. 输入任务:`列出当前目录的文件` → 观察完整闭环
5. 接着追问:`其中有几个 .md 文件?` → 验证多轮上下文延续
6. 输入 `q` 退出 → 退出码 0

## 观察点(通过标准)

| # | 观察点 | 标准 |
| --- | --- | --- |
| 1 | tool_use | 模型真的调用了 bash(命令正确) |
| 2 | 工具输出 | 列出的文件列表与真实目录一致 |
| 3 | 最终文本 | 模型基于结果说出总结性回复 |

## 失败判读

| 现象 | 判读 | 动作 |
| --- | --- | --- |
| 402(余额不足) | DeepSeek 特有,不是代码问题 | 充值或换 key,重跑 |
| stderr 出现"跳过未知响应块" | 降级在工作(模型回了不认识的块) | **不算失败**,继续观察 |
| 其他任何异常 / 挂死 | 真问题 | **完整报错贴给我**,我诊断 |
| SDK × DeepSeek 兼容性失败 | 风险闸门触发 | 我写 `HttpLlmClient` 后备(约 120 行,接口不动实现可换) |
