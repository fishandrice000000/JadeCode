# TUI 修正与统一运行配置

## 本轮目标与范围

用户于 2026-10-19 要求修正审批双高光、输入 `/` 即显示候选，并调整压缩默认值与管线，
把原 `tui.json` 合并进 `~/.jadecode/config/config.json`。只改这三项及必要装配／文档，
不扩展课程章节，不改模型、认证、记忆机制或 Agent 调度。

依据为指定的 Claude Code 2.1.88 研究笔记
`../explore-mature-agents/research-notes/context-compaction/claude-code/03-default-behavior-and-feature-gates.md`。
它明确区分单条转存（默认开启）与整批合计预算（默认关闭），不能把二者都叫 budget 后混用。

## 设计与契约

1. Theme 对每段样式先重置，再应用该段样式；反色、粗体、斜体不泄漏到相邻片段。
2. 命令候选附在编辑器上方，不夺走草稿焦点；输入 `/` 或命令前缀即出现，继续输入筛选，
   上下选择、Tab 补全、Enter 执行，Esc 收起。只列已有 `/help` 与 `/theme`。
3. 默认自动管线：单条超大结果转存 → 超字符阈值时摘要。聚合批次预算、snip、micro、fit、
   响应式补救默认关闭，可在配置中分别开启。手动 compact 不受自动摘要开关影响。
4. JadeCode 仍按序列化 Java 字符数估算，不照抄 Claude Code 的 token 常量当字符。
   默认总门槛 300,000 字符、单结果 50,000、摘要输入 400,000、摘要输出 8,000 token；
   前两项明显大于原教学门槛，但不是任意模型窗口的精确保证，须按实际后端调整。
   原课程值保留为明确命名的教学配置，生产装配不再使用它。
5. config.json 分为 `tui` 与 `compaction`；所有压缩阈值和自动管线开关均可覆盖。
   模型及凭据仍来自原环境配置，不迁入本文件。配置启动时加载，修改后重启生效。
6. 无配置文件用默认值；显式非法配置报出字段名，不静默忽略。主题保存只修改 `tui.theme`，
   保留压缩配置及未知字段，同目录临时文件后替换；不把完整配置输出到终端。
7. 兼容迁移旧 tui.json：新值优先，只迁移旧主题；保留旧文件作为恢复材料，不再更新它。
   本机修改前备份，新配置不得覆盖已有用户字段；验证只使用临时配置与假模型。
8. 父、队友及一次性子代理使用同一设置快照；禁止关闭响应式开关后仍偷偷重试。
   旧课程验证明确选择课程管线，不让测试通过依赖机器级配置。

## 工程步骤与 Git

- 第一笔：审批样式隔离、实时命令候选及本任务单。
- 第二笔：统一配置、压缩默认／开关、旧主题迁移、必要的现有验证适配与使用说明。
- 精确暂存，不包含既有 ADR 删除、旧学习答案、`docs/reviews/`。不 push、不改历史。
- 不新增永久单元测试；构建、相关现有定向测试及临时假模型／PTY 检查。
- 实现、工程自审、验证、提交、用户真机验收分别记录。下文结果在执行后补充。

### 对齐范围

只调整已有策略的生产默认启停，不声称移植 Claude Code 全部上下文机制：

- 不新增硬阻塞线、缓存共享、远端开关、时间微压缩、摘要重试或 SDK 服务端上下文编辑。
- 继续保护未消费的最新交换、先归档后摘要，原归档和失败契约不变。
- read_file 仍由 JadeCode 普通单项转存保护，没有引入 Claude Code 的独立读取上限／例外。
- 可选聚合预算仍是原课程算法，只选择超过单项门槛的结果；总量超线不保证一定能缩回线内。
  micro 开启后也仍是课程的长度触发版，不是 Claude Code 的时间触发版。
