# TUI 滚动、角色标签与表格修复

## 目标与范围

本轮按用户反馈修复三项显示问题，不重写 Session、Team、审批或消息历史：

- 主屏内联模式不捕获鼠标，交还终端原生滚轮、拖选与复制。审批卡片保留方向键／Tab／Enter；工具和思考用 Ctrl+O／Ctrl+T。暂不保留鼠标点击卡片。
- 没有存活常驻队友时隐藏 Leader 标签；一次性 Subagent 不视为 Team。保留内部 actor ID、审批关联及 token 统计口径。
