# 工具预览对比度与标题分隔

## 本轮目标与范围

用户希望工具结果默认灰色，手动展开后才采用普通正文色；Tool／Thinking／Reply 等标题右侧补一条低对比度细线。另修正 /model 的多行字段被 Markdown 软换行合并的问题。

只修改 ConversationView、Theme、TuiController 的模型信息条目类型及必要说明。折叠／展开不修改工具结果原文、状态或模型历史；正常正文色随主题／终端前景色，不在浅色主题硬编码不可读的白色。保持 NO_COLOR 不发颜色控制序列，窄窗口不越界。

验证：构建、临时显示副本检查（折叠与展开的样式、流式／隐藏思考标题、窄窗口、模型字段换行、无色模式）。不新增永久测试，不调用真实模型；用户真机确认实际灰度与分割线观感。自审后精确本地提交，不 push；保留已有用户改动。

## 结果

- 实现与工程自审 Pass：折叠／展开只改样式；标题文字保留状态色，细线用淡灰样式；隐藏思考标题也有细线；/model 用独立 Model 显示类型保留每个字段的换行，不再交给 Markdown 合并。
- `mvn -q -DskipTests package` 退出 0。临时离线检查覆盖上述样式、缓存重排、NO_COLOR、窄窗口及 /model 不请求模型；没有新增永久测试、读取凭据或调用真实模型。
- 实际灰度与线条观感仍待用户重启 TUI 复核。工具展开使用终端普通前景色，在默认深色终端呈白色，不对浅色主题硬编码白字。
- 阅读入口：ConversationView.entry/header → Theme.encode → TuiController.open；只处理显示副本，不改变 Agent 数据流。可对照 `docs/notes/s13/tui-contrast-review.md` 阅读。
