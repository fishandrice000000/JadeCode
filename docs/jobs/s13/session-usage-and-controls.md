# 会话用量、思考设置与退出交互

## 1. 目标和范围

按用户确认的方案扩展已有 TUI 与会话保存：隐藏零后台数及未报告用量，缩写 Token 数；
将 Leader、队友、一次性子代理、记忆、摘要、辅助审批的已报告用量归入当前用户会话；
显示有依据的上下文剩余比例，精简 `/model`，增加 `/thinking`、`/rename`、名称恢复、
`/quit` 与 `/exit`。退出恢复终端后显示会话身份，启动不再固定显示 UUID。

不改模型、认证、API Key、依赖或已有压缩策略，不引入独立统计服务或 workspace 包。
保护本轮开始前的三份文档删除、三份旧笔记编辑与未跟踪 docs/reviews/。

## 2. 职责和数据流

- llm：单次请求设置、服务商字段转换、用量记录与统一调用包装。
- session：并发调用的累计账本、当前 Agent 的占用快照、会话设置。
- session.history：单个写者保存用量/设置/改名事实，清单保存可重建的汇总，兼容旧日志。
- bootstrap：为各 Agent 和用途注入统计客户端，不嵌套包装造成重复计数。
- cli / cli.tui：本地命令、只读快照、候选选择、显示和退出；不自己算账、不请求模型计数。

累计花费与上下文占用分开：前者包括整个用户会话，后者只描述当前主 Agent。
占用采用最近正式请求的服务端输入加输出；历史改变后失效，无依据时隐藏，不按字符伪造 token。

## 3. 持久化和失败契约

1. 每次调用生成唯一编号，最终响应只记一次；流增量不累计，恢复不重算成新的调用。
2. 用量包括已发生但业务校验失败的响应；服务商未报告/断流无法取得的用量不编造。
3. 用量不成为模型消息；元数据事件不覆盖 Todo，不因压缩/回滚撤销花费。
4. 旧日志读取兼容；没有历史用量就是缺资料，不通过字符数补账。
5. 统计写入使用原会话写者和锁；会话关闭后不写进新会话，不重新执行业务补统计。
6. 名称不作为目录名。重复名称必须选择，不默认打开第一项；UUID 仍是唯一身份。
7. 思考强度从下一次完整请求生效，旧响应/工具交换不改写；未适配后端不假装支持。
8. `/quit`、`/exit` 关闭整个会话，复用队友/后台/日志清理；不等于单轮取消。

## 6. 自审修正和限制

- 已修正异步元数据操作的目标核对：保存时检查原 UUID，不能串到后来打开的会话。
- 本地设置写入按确认顺序串行执行，避免旧选择后写覆盖新选择；正常退出等已提交的本地元数据写入，
  不是等业务任务完成。强制杀死进程仍不保证处理尚未执行的操作。
- 百分比改用整数计算，避免浮点误差把恰好 80% 显示成 79%。
- 临时驱动初轮有两处 Java 调用写法错误、一处预期百分比算错，以及 PTY 关闭先返回 EIO 后未回收进程的
  驱动错误；保留首次错误并修正检查工具后通过，没有靠改产品逻辑迎合错误断言。
- 日志版本升到 2，新读取器兼容版本 1；旧版 CLI 不保证可读取新记录，不能用降级二进制继续写同一日志。
- 统计只覆盖取得报告的调用，历史缺失、断流或服务商未报告无法补造，也不是金额统计。
  一次性子代理的摘要记在拥有共享压缩器的 Agent 下；总量与 SUMMARY 分类不漏计或重复。
- 上下文百分比采用最近正式请求报告，不承诺精确剩余输入额度；历史变化、刚恢复或窗口未知时隐藏。
- 思考切换目前适配 DeepSeek 官方与 Anthropic Opus/Sonnet 4.6；其它端点保留默认，不假称参数生效。
- 原有笔记中的两处行尾空格属于用户既有编辑，未处理；只检查本轮精确路径和暂存区的空白错误。
- 打包后 `./jade --version` 通过；额外查看用法时发现既有 `repl` 子命令没有注册 `--help`，
  返回用法与退出码 2，未启动模型。此非阻塞原有行为未扩展修改，不计入上述通过项。
