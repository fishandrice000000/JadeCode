# 会话列表、轮次格式与底部输入区

日期：2026-10-20；起点：8281c70。

## 用户需求与范围

1. resume 候选只显示会话名和距上次使用的时间，不显示 UUID 或 UTC 长时间戳。
2. 轮次计时不足一分钟用 0.0s；分钟以上用 1m02s 等紧凑格式，秒位没有小数。
   状态栏及 Reply 共用格式，单工具仍保留毫秒显示，计时算法不变。
3. 收起候选后输入区不能留在窗口中间；状态、编辑区域与页脚作为整体贴住底部。

不修改压缩/记忆策略、Agent 执行、模型协议或持久日志；不修复之前留档的其它 TUI 问题。
不新增永久单元测试、不调用真实模型、不修改用户已有笔记、文档删除或 docs/reviews。

## 设计

- SessionPicker 使用 UUID 作内部选择值；SelectList 将选择值和显示标签分开。
  同名且同一时间使用的两项不会相互覆盖；名称筛选不匹配隐藏 UUID。
  时间以打开列表时为准，显示刚刚、分钟前、小时前、天前；未来时间因校时按刚刚处理。
- ConversationView.turnDuration 仅格式化整轮时长：0.3s → 29.0s → 1m02s → 1h02m03s。
  固定整轮起点和最终冻结值不变；工具仍用 duration。
- Frame 标明底部区域的开始位置，InlineRenderer 在其前面补显示空行。
  短对话补到窗口高度；曾滚动的长对话维持当前可见区底部，收起候选留下的空位转到输入区上方。
  新消息增长时消耗这些空位，不向模型历史或日志写空消息。光标和审批 hit 一起平移。
  尺寸/主题或已滚出视口的旧内容变化仍沿用原来的重放策略，不为每次关菜单清 scrollback。
