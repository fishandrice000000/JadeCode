# Java Code Review

基于仓库中的实际代码和 diff 做审查。先理解行为契约及调用链，再判断实现是否满足它们。

重点检查：

- 正确性、边界条件、异常语义和资源生命周期；
- 路径、命令、权限及不可信输入造成的安全问题；
- 与现有接口、调用方和测试约定不一致的回归；
- 缺失但能捕获真实故障的测试。

按严重程度列出 findings，并给出文件与行号。区分阻塞问题、非阻塞风险和纯风格建议。
如果没有发现问题，明确说明，同时指出仍未覆盖的验证范围。除非用户同时要求修复，否则不要修改文件。
