# Maven Test Diagnosis

先复现最窄的失败，再读取完整错误链和对应的 Surefire 报告。不要被后续级联错误带偏，优先定位第一个可解释其余失败的根因。

诊断时区分：

- 主代码编译失败；
- 测试代码或 fixture 自身错误；
- 行为断言揭示的产品回归；
- JDK、Toolchain、权限、网络或平台差异造成的环境问题。

报告应包含失败测试、直接证据、根因、影响范围和最小修复建议。若用户只要求诊断，不修改代码；若用户明确要求修复，实施最小改动，先跑定向测试，再跑完整测试集，并分别报告结果。
